# Citation and License

Source: OpenAlex Works API.

OpenAlex developer documentation describes OpenAlex as a fully open catalog of scholarly works, authors, sources, institutions, topics, and more, and describes the complete dataset as CC0.

Suggested citation from OpenAlex:

Priem, J., Piwowar, H., & Orr, R. (2022). OpenAlex: A fully-open index of scholarly works, authors, venues, institutions, and concepts. ArXiv. https://arxiv.org/abs/2205.01833

This Kaggle package is a derived convenience snapshot built from transparent frontier-AI query terms. It is not an exhaustive benchmark for all AI research and should not be used for research evaluation without checking OpenAlex source records and known bibliometric caveats.
